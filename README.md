### Fullstack Engineering

### Product Development

I enjoy taking an idea from **concept → architecture → design → implementation → deployment**, with an emphasis on solving the actual problem rather than just writing code.

### UI/UX Design

My development process is strongly influenced by design. I use **Figma and UX principles** to create interfaces that are intuitive before turning them into production-ready software.

### AI & Emerging Technologies

I'm actively exploring **AI-assisted development, local LLMs, AI integrations, and intelligent software systems**, with a focus on practical applications rather than AI for the sake of AI.
